# Биоквиз — интерактивная викторина по биологии

**Автор:** Диана Дубовая  
**Проект:** Веб-приложение на Django для изучения строения клетки

---

## Описание проекта

«Биоквиз» — это образовательное веб-приложение, которое позволяет изучать строение клетки через теорию, викторину, интерактивную схему и тест по картинке. Реализован полный CRUD для управления вопросами.

---

## Функциональность

### Основные возможности
- **Теория** — подробный материал о клетках (эукариоты, прокариоты, грибы) с таблицей сравнения.
- **Викторина** — 10 вопросов с выбором ответа, пояснениями и подсчётом баллов.
- **Тест по картинке** — вопросы, где нужно ввести цифру, соответствующую органоиду на схеме (вопросы хранятся в БД).
- **Интерактивная схема** — картинка с наведением и всплывающими описаниями органоидов.
- **Статистика** — отображение количества правильных ответов и процента успеха.

### Управление вопросами (CRUD)
- **C**reate — добавление нового вопроса через веб-форму (`/quiz/add/`).
- **R**ead — просмотр списка всех вопросов (`/quiz/list/`).
- **U**pdate — редактирование вопроса (кнопка «Редактировать» в списке).
- **D**elete — удаление вопроса с подтверждением (кнопка «Удалить»).

### Дополнительно
- Сессионная логика для сохранения прогресса викторины.
- Наследование шаблонов (`base.html`), единый дизайн.
- Валидация форм и понятные сообщения об ошибках.
- Pylint 10/10 (настроен через `.pylintrc`).
